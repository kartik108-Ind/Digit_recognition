About the project

The model was trained on the MNIST dataset of handwritten digits. In the notebook, four models (Logistic Regression, KNN, Random Forest, SVM) were compared and validated. For this website, a small neural network (MLP) was trained on the same data, because it is light enough to run directly in your browser. Nothing is sent to a server.

How a drawing is processed: the digit is cropped, resized to 20 x 20, centred in a 28 x 28 image (like MNIST), and passed through the network, which outputs a probability for each digit.
